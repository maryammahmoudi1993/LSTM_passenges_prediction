# Data

`airline-passengers.csv` is the classic **airline passengers** series: the monthly number of international airline passengers, in thousands
(for example 112 means 112,000 passengers), from January 1949 to December 1960: 144 months, no missing values.
It is a byte-for-byte copy of the file `airline-passengers.txt` in [`../legacy`](../legacy) (2 KB), which I used in the first version of this project.

- **Origin:** this is the series known as `AirPassengers` in many software packages and as "Series G" in G. E. P. Box and G. M. Jenkins, *Time Series Analysis: Forecasting and Control*.
  This attribution is from my memory of the documentation of those packages; I could not re-check it from the environment in which this was written.
- **Licence / terms:** I could not verify the terms of use of this particular file or of the original publication from the environment in which this was written.
  The file is tiny and widely distributed, but please check before reusing it for anything else.

Nothing else is downloaded; no other data is used.
