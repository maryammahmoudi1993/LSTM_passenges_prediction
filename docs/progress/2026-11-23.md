## Results (from the executed notebook; test months 1959 to 1960; MAE in thousands of passengers)

| Task | Model | MAE |
|---|---|---|
| A (one month ahead) | naive / seasonal naive | 44.2 / 47.6 |
| | SARIMA / Holt-Winters / Prophet | 12.5 / 12.2 / 17.6 |
| B (24 months ahead) | naive / seasonal naive | 115.2 / 71.2 |
| | SARIMA / Holt-Winters / Prophet | 42.0 / 29.0 / 25.5 |

SARIMA and Holt-Winters are practically tied in task A; the ranking changes in task B (Prophet first). Seasonal naive is slightly worse than naive on the test months of task A although much better on validation (the series grows).
Prophet was installed without problems (PyPI wheel); no fallback model was needed. The notebook gives identical numbers on every run (the classical models are deterministic).
